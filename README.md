# TheFartButton

This project aim to be a website that is being updated with some random features with no actual plan. The wish is to make it a "Community Driven Project", where the community decides which is/are the next feature(s) on the website. Features can be anything as long as it is morally acceptable. The term "morally acceptable" is totally subjective from the development team point of view. 

The resulting website can be seen here: http://thefartbutton.net

## Current behavior (v0.1)
- There is a red button in the center of the screen that when you click on it makes a fart noise and "throws" a fart. Sometimes it bamboozled you by throwing a "lol" instead of a fart. 
- There is a "fart counter" that is incremented each time a fart is thrown.  

## Basic rules (can evolve)
- No AI
- No COOKIES
- Vanilla HTML/CSS/JS (no framework, libs are ok tho)
